# Tarjeta profesional

Página de presentación profesional de Oiane L., en español e inglés.

- React + Vite, sin backend.
- El idioma elegido se guarda en el navegador (localStorage).
- Textos y datos editables en `src/content.js`.

## Antes de publicar

En `src/content.js`, sustituye los marcadores de `CONTACT` por tus datos reales y añade los enlaces de `PROJECT_LINKS`.

## Comandos

```bash
npm install
npm run dev      # desarrollo
npm run build    # genera la carpeta dist
```
